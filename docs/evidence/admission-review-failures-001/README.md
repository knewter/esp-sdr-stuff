# Admission defects found before hardware use

October 4, 2026: **two isolated host preparations require corrections**.
[Checks and retained proof hashes](checks.json) identify the original subjects
and independent probes. Neither preparation is admitted for hardware.

The initial Forgix register-runtime subject passed 123 author groups. Six peer
groups then reproduced three defects: a changed original USB identity or flash
baseline could retain the same qualification, final lease release could exceed
the overall deadline while returning success, and a release error could leave
the authoritative session marked completed. The empty production registry
continues to refuse physical access. The historical configuration artifact also
correctly refuses its stale build inputs; a fresh ARM artifact remains required.

The initial outer ESP receiver holder passed 40 author groups. Six independent
groups reproduced late successful finalization, a prematurely completed
intermediate receipt, permissive controller field types, and loss of the
exclusive safety lock on a replacement-keeper directory error. The last defect
was observed using real disposable processes and a temporary regular-file
flock, with no hardware. The failed subject and exact probes are retained.

Corrections are underway in isolated worktrees. They must pass the original
counterexamples and independent review before root admission. Receiver input
transfer and [read-only root preparation](../ble-primary-receiver-root-preparation/README.md)
remain separately verified; that proof does not qualify the operator holder.
Likewise, earlier synthetic lifecycle/runtime evidence does not qualify this
new register implementation.

No device, Docker daemon, controller or producer was accessed by these peer
probes; no compiler or physical trial ran. Group counts describe author checks
and deliberately reproduced counterexamples, not successful admission tests.
No hardware checkbox, RF claim, original Trial B gate or accepted requirement
changes. Raw identities, original firmware, private scripts and process receipts
remain unpublished.
