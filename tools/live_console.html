Switch to BLE snapshot decode to run the bounded LE1M decoder on every window.
Wideband mode streams on-device FFT frames (uncalibrated power codes, gaps between snapshots). Decode mode stacks each window's 63 time slices in the waterfall (black line = gap until the next window). It pulls 16 MS/s, 8-bit IQ windows of 1.02 ms each, at about 2.5 per second, then runs the legacy and extended-primary LE1M decoders. This board's carrier sits about 0.8 MHz above nominal, so ch37 shows near 2402.8 MHz. A packet only counts once its CRC passes. Addresses never leave the server; packets appear as per-run salted hashes.

The RTL is tuned 300 kHz off the station so its DC spike stays off the carrier. The pipeline runs a channel filter, decimates to 240 kHz, FM-demodulates, and feeds the MPX to redsea, which does RDS sync and checkword decoding. Audio goes through a 15 kHz low-pass, 48 kHz, and 75 µs de-emphasis.
